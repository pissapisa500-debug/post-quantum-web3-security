# Post-Quantum Crypto Defender — Roadmap

[![Status](https://img.shields.io/badge/Status-Active%20Development-green.svg)](https://github.com/pissapisa500-debug/post-quantum-web3-security)

## Phase 1: Foundation (May — June 2026) — **Completed** ✅

- [x] Project architecture and structure
- [x] Hybrid signature scheme (Ed25519 + Falcon-512)
- [x] CLI tool with key generation, signing and verification
- [x] 8+ unit tests passing, CI/CD green
- [x] Improved documentation and README
- [x] Published Telegram channel (2,700+ community)

## Phase 2: Core Features (June — July 2026)

- [ ] Add support for Dilithium2 and Dilithium5
- [ ] **Solana integration library** (transaction signing with hybrid keys)
- [ ] **Aptos/Move integration** (port Rust library to Move module)
- [ ] Key rotation and migration utilities
- [ ] Comprehensive testing + performance benchmarks
- [ ] Examples for Solana wallets (Phantom, Solflare) and Aptos wallets (Petra, Martian)

## Phase 3: Product & Adoption (July — September 2026)

- [ ] Release v0.1.0 on crates.io
- [ ] Full documentation with usage guides and examples
- [ ] Web demo dashboard (Next.js + Solana + Aptos)
- [ ] Security audit preparation
- [ ] Community building and developer outreach in Solana + Aptos ecosystems

## Phase 4: Ecosystem Growth & Scaling (Q4 2026)

- [ ] Support for Kyber / ML-KEM (post-quantum KEM)
- [ ] Zero-Knowledge friendly post-quantum constructions
- [ ] Integration with Anchor framework (Solana) and Move (Aptos)
- [ ] Partnerships with wallets, dApps, and infrastructure projects
- [ ] Professional security audit

## Long-term Vision (2027+)

To become the leading open-source infrastructure for **post-quantum cryptography** in Solana, Aptos, and the broader Web3 ecosystem, ensuring long-term security against quantum computing threats.
