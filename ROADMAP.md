# Roadmap

## Phase 1: Foundation (0-4 weeks)
- Research NIST PQC standards (Dilithium, ML-KEM, Falcon)
- Project architecture design
- Initial Rust skeleton with hybrid cryptography modules
- Basic documentation

## Phase 2: Core Implementation (4-12 weeks)
- Hybrid signature scheme (secp256k1 + Dilithium)
- Key migration and rotation tool
- Basic CLI interface
- Unit tests + Ethereum testnet integration tests

## Phase 3: Release & Community (12-20 weeks)
- v0.1.0 public release
- Examples for wallet and dApp integration
- Security audit preparation
- Documentation website (optional)

## Future
- Support for more PQC algorithms
- ZK-friendly post-quantum proofs
- Integration with popular wallets
